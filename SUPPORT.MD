# Support

This is a personal project and does not provide a formal support contract.

## Bugs

Use a GitHub Issue for reproducible problems with the repository or its documented behavior.

Include:

- what you expected;
- what happened;
- enough context to reproduce it;
- relevant environment information;
- relevant error output with secrets removed.

## Security

Do not use a public Issue for a security vulnerability.

Use GitHub Security Advisories and follow [`SECURITY.md`](SECURITY.md).

## Architecture

Repository-owned product, architecture, design, and implementation material lives in `context/` and `content/`.

`AGENTS.md` defines the repository-local agent operating rules.

## No Guarantees

Support, response times, fixes, releases, and compatibility are not guaranteed.
