# Loaded Vibes: Deliver

Perform delivery only when requested/authorized.

1. Inspect Git status, branch/base, repository instructions, linked Issue/PR, and existing conventions.
2. Review the diff before commit.
3. Ensure completion claims map to fresh verification evidence.
4. Keep commits focused and preserve unrelated work.
5. Use repository-native Issue/branch/PR conventions; link acceptance criteria to evidence where applicable.
6. Do not force-push, delete branches, merge, deploy, or perform other consequential actions unless the request and repository rules authorize them.
7. After external GitHub mutations, read back the resulting state before claiming success.
8. Use the bundled commit/PR instruction references when preparing messages.
