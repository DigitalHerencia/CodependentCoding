# LV-109 — Live preview and recipe handoff

## Outcome

Let users see a representative version of the application they are configuring and move that recipe into the CLI with one obvious action.

## Scope

- add representative preview surfaces for dashboard, onboarding, settings, billing, detail/workflow, and marketing;
- bind preview appearance/content to supported design/product recipe fields;
- provide copyable CLI command and downloadable `loadedvibes.json`;
- keep preview representative rather than executing a remote generation/build service.

## Acceptance

- meaningful recipe changes are visible in preview;
- the downloaded recipe is accepted by the CLI/core;
- the copied command corresponds to the reviewed configuration or references the exported recipe;
- preview does not claim unsupported generated behavior.
