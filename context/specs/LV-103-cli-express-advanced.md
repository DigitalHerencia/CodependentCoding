# LV-103 — CLI Express and Advanced experience

## Outcome

Make the terminal experience feel like configuring a product, not answering framework trivia.

## Scope

- preserve `@clack/prompts`;
- add product-shape selection;
- add capability selection;
- add product identity and supported design choices;
- provide Express and Advanced modes over the same recipe;
- show a concise review before generation;
- improve progress/success output around user-relevant phases.

## Acceptance

- a first-time user can generate a project through Express mode with a small number of meaningful decisions;
- Advanced mode exposes all supported recipe choices;
- no prompt asks about fixed architecture internals;
- review clearly shows included and excluded capabilities before files are created.
