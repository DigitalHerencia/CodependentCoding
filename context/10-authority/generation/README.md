# Codependent Coding™ Generation System Authority Bundle

This bundle intentionally separates three authority concerns.

## 1. Hipster Stack™ Constitution System

Owns:

```text
technology stack
Virgule schema
normalization
dependency closure
generation plan
artifact ownership
transforms
materialization
CLI
```

## 2. Maximal Template™ / Arrangement™

Owns the distinction between:

```text
Maximal Template = runnable superset source
Arrangement      = generated standalone application
```

## 3. Generation Pipeline Integration

Defines the end-to-end handoff:

```text
Ontology
→ Virgule
→ Hipster Stack + Maximal Template
→ Arrangement
```

## Why split it

The generator is not the template, and the template is not the generated application.

Keeping those boundaries as separate authority packages prevents generator metadata, source-library ownership, and generated-app runtime concerns from collapsing into one vague “generator” document.

## Canonical short definitions

| Unit | Definition |
|---|---|
| The Hipster Stack™ Technology Stack | Concrete technology stack plus deterministic constitution/generation system and CLI |
| The Virgule™ Application Definition | Dependency-closed resolved authority for materialization and preview |
| The Maximal Template™ Domain Library | One runnable superset application containing every supported implementation |
| The Arrangement™ Generated Artifact | Generated standalone white-label application |
