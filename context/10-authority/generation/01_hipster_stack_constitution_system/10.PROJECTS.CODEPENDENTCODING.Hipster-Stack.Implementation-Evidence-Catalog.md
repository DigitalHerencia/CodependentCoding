# 4. Current Materialization Evidence

`packages/core/src/generator/plan.ts` creates a staging path and resolves excluded owned paths.

`packages/core/src/generator/materialize.ts`:

1. verifies template metadata;
2. creates staging;
3. copies template;
4. removes excluded owned paths;
5. applies transforms;
6. promotes staging to target;
7. cleans staging on failure.

This strongly aligns with the canonical safe-materialization model.
