## Visual Vibes requirements

Use a shared design system, not page-local imitation:

- black / near-black canvas;
- cyan/steel signal accents and restrained glow;
- high-contrast uppercase display hierarchy;
- monospaced UI/code surfaces;
- thin technical borders and circuit/industrial motifs;
- large negative space around branded titles balanced by dense workbench/code panels;
- Digital Herencia landscape/footer treatments;
- semantic token ownership for color, border, typography, radius, spacing, focus, state, and code presentation;
- responsive behavior and accessible focus/contrast preserved.

The mockups may be improved where needed for readability, responsive behavior, accessibility, actual control density, or real source/data shape. Do not preserve a visually attractive dead control.

## Code explorer reuse

The imported Codebase Context Utility contains file-tree/code-preview mechanics. Reuse/adapt those mechanics for Ontology, Simples, and Maximal explorer surfaces when they materially reduce implementation work. Do not carry forward its old Next 14 app, dependency versions, or standalone product identity as a separate runtime application.
