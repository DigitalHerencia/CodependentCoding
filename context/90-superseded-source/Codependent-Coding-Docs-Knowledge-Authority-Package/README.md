# Codependent Coding™ Docs Knowledge Authority Package

This package defines how the existing `DigitalHerencia/CodependentCoding` knowledge repository becomes the documentation section of the new Codependent Coding™ website.

## Source areas

```text
docs/
patterns/
.agents/contracts/
provenance/
```

## Package files

1. `10.PROJECTS.CODEPENDENTCODING.Docs.Authoritative-Knowledge-System-Spec.md`
   - governing authority model
   - four-area knowledge architecture
   - content classes
   - knowledge modeling
   - patterns/contracts/provenance relationships
   - website-docs invariants
   - reconciliation with current product direction

2. `10.PROJECTS.CODEPENDENTCODING.Docs.Canonical-Knowledge-Catalog.md`
   - current `docs/` inventory
   - current `patterns/` inventory
   - current `.agents/contracts/` inventory
   - current `provenance/` inventory
   - artifact role matrix
   - core/supporting pattern catalog
   - current product reconciliation requirement

3. `10.PROJECTS.CODEPENDENTCODING.Docs.Website-Information-Architecture.md`
   - proposed docs navigation
   - source-to-page mapping
   - page metadata
   - cross-linking rules
   - discovery facets
   - docs page anatomy

4. `10.PROJECTS.CODEPENDENTCODING.Docs.Reconciliation-and-Migration-Guide.md`
   - controlled migration from old corpus to new product topology
   - identity reconciliation
   - pattern/contract/provenance migration
   - known hotspots
   - QA and completion standard

## Governing principle

The website Docs are a **presentation and access refactor of the knowledge system**, not a new competing knowledge system.
