---

# 13. Cross-Linking Rules

Every page SHOULD link:

- terms to terminology;
- architecture responsibilities to layer contracts;
- recurring implementation responsibilities to patterns;
- lifecycle references to lifecycle owners;
- machine-enforceable rules to contracts;
- material source questions to provenance.

Do not duplicate the definition in every destination.

---

# 14. Migration Principle

The website Docs are a **refactor of access and presentation**:

```text
repository knowledge
    ↓
reconciled canonical ownership
    ↓
website information architecture
    ↓
rendered Docs
```

They are not:

```text
repository docs
    ↓
AI summary
    ↓
new independent doctrine
```
