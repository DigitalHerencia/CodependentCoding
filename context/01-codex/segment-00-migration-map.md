## Authority overlay

The current handoff package in `context/00-governance/` controls this local build. Older Hipster Stack, Loaded Vibes WebApp Architecture, Knowledge System, Constituter, Libraries, four-preset, and imported-repository names are migration evidence unless explicitly labeled as historical provenance.

## Active wiring observed

- Root `package.json`, `tsconfig.json`, `tsdown.config.ts`, tests, and scripts expect `apps/web`, `packages/{schema,core,cli}`, and `template/`.
- Those canonical runtime paths are not populated in the consolidation workspace yet.
- The working implementations instead remain under the imported paths mapped below.
- `pnpm-workspace.yaml` includes `apps/*` and `packages/*`, so the nested `packages/TheHipsterStackTechnologyStack/*` packages and `src/CodependentCoding-site` are not the intended final workspace layout.
- `node_modules` was not supplied. Build/test claims require dependency installation after workspace wiring is coherent.
- The owner subsequently supplied all ten named mockup files under `docs/mockups/`; that current owner-provided location is the visual acceptance source for Segments 1 and 3-7.

## Migration progress

- Segment 1 moved `src/CodependentCoding-site` to `apps/web`, moved the nested schema/core/CLI packages to `packages/{schema,core,cli}`, and moved root brand assets to `apps/web/public`.
- The empty `packages/TheHipsterStackTechnologyStack` wrapper was removed after root typecheck and the web production build passed.
- Legacy `/libraries/*` and `/configure` paths now redirect to `/simples` and `/anthimeria`; their internal implementations remain migration evidence for later owning segments.
