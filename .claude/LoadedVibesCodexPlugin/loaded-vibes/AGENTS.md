# Loaded Vibes™ Plugin Development Instructions

This repository packages Loaded Vibes™, the Codex execution derivative for Arrangement™ applications.

When changing the plugin itself:

1. Preserve the product boundary: Loaded Vibes operates on Arrangements; it does not become The Hipster Stack generator or The Codependent Coding documentation system.
2. Keep the skill set small and discriminating. Prefer progressive disclosure over giant prompts.
3. Put stable architecture doctrine in `references/`; put repeatable deterministic mechanics in scripts/validators.
4. Do not copy third-party reference-corpus content into the package unless intentionally licensed and attributed. The supplied archive is comparative source material, not plugin payload.
5. Keep validators evidence-based. A mechanical rule may fail only when the code evidence supports the violation.
6. Run `node validators/validate-package.mjs .` before claiming package validity.
7. Run the validator fixture tests under `tests/` before completion.
8. Never claim Plugin Directory publication, installation, agent registration, or runtime enforcement unless independently verified.
