# Code of Conduct

This is a personal software project.

Participation in Issues, pull requests, reviews, and repository discussions should remain focused on the work.

Do not use repository communication for:

- harassment;
- threats;
- doxxing;
- targeted abuse;
- spam;
- publishing another person's private information;
- publishing credentials or sensitive security information.

Technical disagreement is allowed.

Personal abuse is not required to make the disagreement technically interesting.

The maintainer may close, remove, lock, or restrict participation that interferes with the repository or the people working in it.

Security vulnerabilities belong in private security reports, not public discussion.

This code of conduct applies to participation in this repository.
